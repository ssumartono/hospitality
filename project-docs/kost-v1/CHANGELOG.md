# Changelog dokumen

## Revisi 1.1 — 1 November 2026

Target aplikasi ditetapkan **Kost Hospitality v1.0.0 — Production Release**. Status dokumentasi menjadi baseline implementasi siap handoff; tidak ada klaim aplikasi produksi selesai.

- PRD lama diperbarui dalam identitas file yang sama; arsip baseline disertakan sebagai reference.
- Pilot diperjelas: mahasiswi/karyawati Palembang, 12 kamar dua lantai, kamar mandi dalam, prabayar per kamar dan default tanpa deposit; fasilitas/harga bukan asumsi dari demo.
- Scope seluruh 14 modul dibatasi untuk rilis pertama; gateway, SaaS auto-charge, WhatsApp API dan e-sign tersertifikasi ditunda.
- Keputusan transaksi/refund/occupancy/overstay/pindah/cutover dipertegas. Harga bisnis dan retensi yang belum dipilih dipindah menjadi konfigurasi wajib go-live, bukan diisi angka palsu.
- Ditambahkan ADR/data/permission/security baseline, OpenAPI, 60 AC, 60 story dependency, fixtures/CSV, gap register, instruksi developer dan release runbook.
- Semua hasil acceptance produksi NOT RUN; backlog PLANNED; G8 NOT APPROVED. Bukti 39 test prototipe tidak dinaikkan menjadi evidence produksi.
- Tidak mengubah source/hosting mockup, pembayaran nyata, data penghuni produksi, BMC atau harga komersial. Tidak ada deployment aplikasi backend dalam pembaruan dokumen ini.

## Baseline — 30 Oktober 2026

PRD awal aplikasi kost hospitality SaaS dengan alur end to end dan pilot 12 kamar. Baseline berstatus draft desain; tersimpan pada folder reference dan riwayat versi dokumen.
